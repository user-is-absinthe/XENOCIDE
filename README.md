# XENOCIDE

## Играть в браузере

**[▶ Запустить XENOCIDE](https://user-is-absinthe.github.io/XENOCIDE/)**

Откройте ссылку на компьютере, нажмите «Новая кампания» и начните операцию. Нужны клавиатура и мышь. Устанавливать игру не требуется; звук включается после первого действия. Интерфейс игры — на русском.

Игра опубликована через GitHub Pages. Страница репозитория на github.com показывает исходники, а ссылка выше открывает саму игру. Интернет нужен для загрузки страницы; игровых серверов и учётной записи игрока нет.

[English README](README.en.md)

XENOCIDE — одиночный научно-фантастический шутер с видом сверху: орды противников, 20 карт кампании, боссы, 13 видов оружия с альтернативными атаками и улучшениями, импланты, бесконечные экспедиции по seed и полигон с читами. Графика и звук создаются процедурно в браузере.

**Игра создана при помощи GPT-6.1 Sol.**

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение / прицеливание | WASD / мышь |
| Основная / альтернативная атака | ЛКМ / ПКМ |
| Перезарядка / бег / рывок | R / Shift / Space |
| Взаимодействие | E; для терминалов и ремонта удерживайте |
| Смена оружия | Колесо мыши, 1–9; 0 — следующий слот |
| Карта / пауза | M / Esc |

Основные клавиши переназначаются в настройках. После выполнения задачи доберитесь до шлюза и нажмите E.

## Демо

В главном меню нажмите **Демо** и выберите сложность. Компьютер самостоятельно проходит миссии 1–20 по кругу, выполняет задания, покупает оружие, боеприпасы и улучшения, пользуется альтернативными атаками, бегом и рывками, собирает ресурсы и ремонтирует передатчик. После поражения повторяет текущую миссию с новыми покупками.

**Esc** ставит демо на паузу и позволяет выйти в главное меню. При следующем входе можно продолжить сохранённый бой или начать заново с выбором сложности. Демо использует отдельное сохранение в браузере и не меняет кампанию, ручные ячейки и рекорды игрока. JSON кампании не содержит демо.

## Сохранения и офлайн-запуск

Прогресс, настройки, три ручные ячейки и локальные рекорды хранятся в браузере (`localStorage`). Для переноса используйте экспорт и импорт JSON в настройках. Онлайн-версия, локальная папка и разные профили браузера не обмениваются сохранениями автоматически. Если браузер запрещает хранение, экспортируйте JSON перед закрытием игры.

Чтобы играть без интернета:

1. На странице репозитория выберите **Code → Download ZIP** и распакуйте архив целиком.
2. Откройте `dist/index.html` в Microsoft Edge. Сервер, Python и Node.js для игры не нужны.
3. Для переноса на другой компьютер скопируйте всю папку `dist`, включая `src` и `style.css`, и отдельно возьмите экспорт сохранения.

Проверки проекта выполнялись в Microsoft Edge на Windows 11. Для других браузеров, Windows 10 и слабых компьютеров нужна отдельная проверка. Подробности — в [TESTING.md](TESTING.md).

## Разработка

Игра написана на JavaScript с Canvas 2D и Web Audio, без игрового движка и сетевых зависимостей во время игры. Исходники — `src/`, входная страница — `index.html`, переносимая сборка — `dist/`. Открыть корневой `index.html` можно и без сборки.

Для инструментов разработки нужны Python 3.12+, Node.js и Microsoft Edge для браузерных тестов. Устанавливайте зависимости внутри проекта; если `.venv` уже есть, используйте её:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
npm ci --ignore-scripts --no-audit --no-fund
```

```powershell
npm run format
.venv\Scripts\python tools\build.py
.venv\Scripts\python tools\test.py
.venv\Scripts\python tools\browser_test.py
.venv\Scripts\python tools\visual_test.py
.venv\Scripts\python tools\demo_test.py
.venv\Scripts\python tools\demo_edge_test.py
.venv\Scripts\python tools\demo_soak_test.py 3
```

`build.py` обновляет `dist/` и создаёт локальный `XENOCIDE-offline.zip`. `test.py` проверяет синтаксис, ресурсы, карты и соответствие сборки исходникам. Браузерные тесты используют отдельные профили Edge внутри `.venv`; отчёты и скриншоты записываются в `artifacts/`. Окружения разработки, результаты тестов и архив сборки не входят в Git.

### Публикация на GitHub Pages

Workflow [Deploy game to GitHub Pages](.github/workflows/pages.yml) при отправке в `master` собирает игру, выполняет статические проверки и публикует содержимое `dist/`. Его также можно запустить вручную через Actions. Источник в **Settings → Pages → Build and deployment → Source** должен быть **GitHub Actions**. См. [документацию GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
