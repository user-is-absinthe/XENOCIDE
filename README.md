# XENOCIDE

Одиночный офлайн Sci-Fi horde shooter. Оригинальная процедурная графика и звук, русский интерфейс.

## Запуск

Дважды щёлкните index.html в корне или dist/index.html в Microsoft Edge. Интернет и сервер не нужны. Для переноса достаточно всей папки dist. Не перемещайте отдельный HTML без папки src.

**Папка для переноса — `dist`.** Она содержит только `index.html`, `style.css`, `src/` и краткую инструкцию `README.txt` (20 файлов). Скопируйте её целиком на флешку или другой компьютер; остальные файлы проекта не нужны. Перед переносом экспортируйте сохранение JSON в настройках, а на новом месте импортируйте его: браузерное сохранение автоматически вместе с папкой не переносится. В корне также лежит архив `XENOCIDE-offline.zip` с тем же комплектом.

## Управление

WASD — движение, мышь — прицел, ЛКМ — огонь, ПКМ — усиленная атака, R — перезарядка, Shift — бег, Space — рывок, E — взаимодействие, Esc — пауза, M — карта. Колесо переключает купленное оружие; 1–9 выбирают первые девять слотов, 0 — следующий слот. Основные клавиши меняются в настройках.

## Разработка

Готовая игра не требует Python или Node. На компьютере разработчика используются Python 3.12+ и Node.js для проверок синтаксиса. Зависимости устанавливаются только в проект:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
npm install --ignore-scripts --no-audit --no-fund
```

Если политика окружения запрещает системную временную папку, создайте `.venv\tmp` и задайте `$env:TEMP` и `$env:TMP` её абсолютным путём перед установкой. В этой среде именно так настроен Playwright.

```powershell
npm run format
.venv\Scripts\python tools\test.py
.venv\Scripts\python tools\build.py
.venv\Scripts\python tools\browser_test.py
.venv\Scripts\python tools\visual_test.py
```

Сборка копирует локальные ресурсы в `dist/` и создаёт `XENOCIDE-offline.zip`. Тесты Edge используют отдельный профиль внутри `.venv`, не трогают ваш обычный браузерный профиль. Скриншоты и машинный отчёт находятся в `artifacts/`. Пакеты разработки в поставку не входят.

## Кампания и снабжение

В игре 20 авторских карт, 10 основных архетипов и четыре босса, клинок и 12 пушек. Зачистка, терминалы (удерживайте E 1,5 секунды), оборона передатчика, уничтожение гнёзд и аварийные сценарии. После последней миссии открываются экспедиции по seed, с боссом в каждом пятом секторе. Клавиша M показывает цели и выход.

После зачистки нужно самостоятельно добраться до шлюза и нажать E. Между миссиями покупайте оружие, шесть типов патронов, импланты и индивидуальные усиления. Оружие открывается с продвижением по кампании. В кампании только клинок имеет бесконечный ресурс; он способен разрушать гнёзда. При смерти возвращается снаряжение до высадки. Здоровье и купленная броня восстанавливаются перед каждой миссией. За бой без полученного урона и 20 убийств клинком выдаются дополнительные кредиты.

Сложность меняется между миссиями. «Темп волн» задаёт максимальный интервал между волнами: быстрый бой, стандартный, продолжительный. Если все враги уничтожены и очередь появления опустела, следующая волна начинается сразу. После этого изменения тестовый игрок проходит первую миссию примерно за 2,5 минуты; длительность других боёв зависит от оружия и скорости зачистки. В обороне нужно активировать передатчик, сохранить его и отразить все волны — дополнительного ожидания после зачистки нет. Внутри миссии checkpoint сохраняется каждые 30 секунд, при активации терминала и на паузе. Снаряды и краткие эффекты не сохраняются; после восстановления даются две секунды защиты.

## Статус проверки

Проверено в установленном Microsoft Edge на Windows 11, включая запуск `file://` без сети и восстановление после полного закрытия процесса. Тестовый игрок прошёл первую миссию без изменения здоровья и патронов. Все сценарии проверены автоматикой с ускоренным уничтожением врагов; это не полноценное ручное прохождение кампании. Windows 10, баланс всех 20 миссий человеком и производительность слабого целевого ПК требуют отдельной приёмки. Подробности — TESTING.md.

Структура и решения описаны в ARCHITECTURE.md. ROADMAP.md содержит этапы, PROGRESS.md — состояние, TESTING.md — фактические результаты. Сохранения привязаны к расположению HTML и профилю Edge; экспорт JSON позволяет переносить их между папками. Если localStorage запрещён, игра работает в памяти и показывает предупреждение — используйте экспорт.

## Прицел, снабжение и музыка

Во время боя системный курсор скрыт; меню и пауза возвращают его. Под прицелом показано «магазин/всего»: общее количество включает резерв и магазины другого оружия того же типа. При перезарядке появляется круговая шкала, вращающийся маркер, мигающая надпись и оставшееся время.

У каждого из шести типов боеприпасов собственная форма, цвет и подпись. При наведении видно точное название и количество, при подборе — сообщение о пополнении. Раньше один ящик пополнял все открытые типы; теперь такой комплект разложен на отдельные подборы с тем же количеством для каждого типа. Старые контрольные точки совместимы. Недоступное по прогрессу оружие полностью скрыто в магазине.

Музыка синтезируется локально: минорные гармонии, арпеджио, бас и ударные с вариациями. В паузе есть кнопки выключения музыки и общего mute; в настройках — независимые громкости музыки и эффектов. Настройки звука сохраняются. Аудио запускается после первого нажатия пользователя.

## Полигон и чит-коды

Главное меню → «Полигон · уровни и читы». Доступны все 20 карт, в том числе боссы. Из боя настройки читов открываются через паузу. Можно нажимать кнопки или вводить коды в поле и нажимать Enter:

| Код | Действие |
| --- | --- |
| `CREDITS` | Добавить 10 000 кредитов |
| `AMMO` | Включить/выключить бесконечный резерв; магазин перезаряжается обычным способом |
| `NORELOAD` | Включить/выключить мгновенное пополнение магазина из резерва |
| `GOD` | Включить/выключить бессмертие игрока |
| `ARSENAL` | Выдать всё оружие и запас всех типов боеприпасов |
| `BARRAGE` | Выдать и выбрать экспериментальный «Ракетный шторм»: темп ПП, бесконечные ракеты, без перезарядки, только на полигоне |

Для непрерывной стрельбы включите `AMMO` и `NORELOAD` вместе. Ограничение скорострельности и заряд рельсотрона остаются. Бессмертие не отменяет сценарный таймер и необходимость защиты передатчика.

Полигон использует копию профиля в памяти. Читы, деньги и прохождение в нём не записываются в сохранение кампании; после выхода в главное меню возвращается исходный профиль и его контрольная точка. Для импорта/экспорта и сброса сохранения сначала выйдите из полигона.

Дополнительная проверка обновления: `.venv\Scripts\python tools\enhancements_test.py`. Она запускает автономный dist в Edge без сети, проверяет функции и сохраняет скриншоты в artifacts.

## Подсказки оружия и горение

Наведите мышь на карточку оружия в магазине, чтобы увидеть короткое описание, сильные и слабые стороны. Подсказка доступна и при выборе карточки/кнопки клавишей Tab, закрывается клавишей Esc и не мешает покупкам. Закрытое оружие по-прежнему не показывается.

После огнемёта враги покрываются анимированным пламенем с искрами и дымом. Эффект виден на всех уровнях качества и постепенно гаснет к окончанию горения. Урон и длительность горения остались прежними.

Проверки подсказок, огня и досрочных волн: `.venv\Scripts\python tools\pace_test.py`.

В миссиях обороны 4 и 9 над передатчиком постоянно показана полоска здоровья с процентом: зелёная выше 50%, жёлтая при 26–50%, красная при 25% и ниже. Она видна до и после активации, поверх врагов и освещения, не перекрывает подсказку E. Проверка: `.venv\Scripts\python tools\defense_test.py`.

У купленного оружия в магазине показано, что даёт усиление: +12% базового урона за ступень, максимум +36%, текущий бонус и урон до/после следующей покупки с учётом импланта усилителя. Для дробовика указана одна дробина, для Теслы — первая цель, для взрывчатого оружия — центр взрыва, для огнемёта — суммарный урон струи одного выстрела без последующего горения. Это значения ЛКМ до сопротивлений врага. На максимуме цена скрывается, кнопка подписана «Максимальное усиление». Переносимая папка и эффекты улучшений проверяются командой `.venv\Scripts\python tools\portable_test.py`.

## Очки и таблицы лидеров

Аптечка остаётся на земле, пока здоровье полное. При ранении она подбирается автоматически; лишние аптечки не расходуются после полного лечения.

За успешный выход через шлюз начисляются очки за скорость, отдельно от кредитов. Текущий возможный результат виден в HUD, итоговый — на экране победы. Формула: `floor((10000 + 500 × уровень) × множитель сложности × 180 / (180 + секунды боя))`, минимум 1 очко. Множители четырёх сложностей: 0,8 / 1 / 1,3 / 1,6. Пауза и время в меню/магазине не учитываются; поражение очков не даёт.

Главное меню → «Таблица лидеров»: имя для будущих результатов, таблицы всех 20 уровней и полной кампании, фильтры сложности и темпа. Хранятся десять лучших результатов для каждой комбинации условий; выбранная таблица показывает топ-10. Сначала сравниваются очки, при равенстве — меньшее время.

Результат кампании — сумма первых побед на уровнях 1–20 по порядку за одно прохождение. Переигровки не добавляют очки повторно; общее время включает завершённые неудачные и дополнительные бои, паузы исключены. Изменение сложности/темпа помечает полный результат как смешанный. Промежуточный счёт сохраняется между сессиями. При загрузке старого профиля прежние результаты не выдумываются: начните с уровня 1 для нового полного зачёта.

Рекорды локальные, доступны без интернета, входят в экспорт/импорт JSON и сохраняются при начале новой кампании. Полный сброс удаляет их с подтверждением. Полигон не записывает рекорды. Проверки: `.venv\Scripts\python tools\records_test.py`.

## Версия 1.1.0 — развитие бойца и оружия

Номер версии показан крупно, приглушённым цветом в правом нижнем углу главного меню. Старые профили и контрольные точки поддерживаются; новые улучшения начинаются с нулевой ступени.

Новые импланты в магазине:

| Имплант | Эффект одной ступени | Максимум |
| --- | --- | --- |
| Каскад рывков | +1 заряд | 5 зарядов, 4 покупки |
| Форсаж спринта | +7,5% базовой скорости бега с Shift | +37,5%, 5 покупок |
| Энергоконтур | +25 выносливости, +3 ед./с восстановления | 225 выносливости и 38 ед./с, 5 покупок |
| Волновая регенерация | Лечение 4% максимального HP после полной зачистки волны | 20%, 5 покупок |

Каждый рывок требует отдельного нажатия Space; заряды восстанавливаются по одному за 2,4 секунды, между готовыми зарядами ждать не нужно. HUD показывает число зарядов и таймер следующего, выносливость — текущий и максимальный запас. Старые сервоприводы по-прежнему улучшают обычное перемещение, форсаж отдельно усиливает спринт. Регенерация не срабатывает по таймеру появления следующей волны, пока остаются живые враги/очередь появления, и не воскрешает погибшего бойца.

У каждого обычного оружия две независимые ветки по три ступени: прежний урон и новое развитие. Карточки показывают эффект и значения до/после покупки. Для большинства пушек новая ветка сокращает базовую паузу между выстрелами на 8% за ступень (до −24%). Особые ветки:

| Оружие | Эффект ступени |
| --- | --- |
| Клинок | +15% дальности удара |
| Огнемёт | +15% дальности и +12% угла струи |
| Плазменный карабин | +15% скорости снаряда |
| Гранатомёт | +12% радиуса взрыва |
| Рельсотрон | −12% базового времени заряда |
| Тесла-пушка | +1 цель в цепи обоих режимов |

Полностью заряженный рельсотрон проходит сквозь стены и врагов до своего предела пробития/дальности. Стены остаются на месте; выстрел не может покинуть границы карты. Ускорение зарядки учитывается в HUD и условии пробития.

В настройках есть кнопка «Разблокировать бесконечный режим». Она открывает экспедиции с 21-го сектора без отметки о прохождении кампании. Разблокировка сохраняется между запусками, переносится через JSON и остаётся при новой кампании; полный сброс её удаляет.

В обеих миссиях обороны (4, 9) активированную установку можно бесплатно ремонтировать: стойте рядом и удерживайте E. Восстанавливается 30 HP/с, стрельба во время ремонта остановлена. Через стену, издалека или после уничтожения ремонт невозможен. Подсказка над установкой и цель в HUD показывают ремонт; восстановленное здоровье сохраняется в checkpoint.

`BARRAGE` работает только на полигоне. Экспериментальная ракетница стреляет с базовой паузой 0,065 с, не тратит боеприпасы и не требует перезарядки; AMMO/NORELOAD для неё не нужны. Код выбирает её сразу, а введённый до высадки — при старте миссии. Обычный ARSENAL выдаёт 13 штатных видов оружия. Экспериментальное оружие скрыто из магазина, не переносится в кампанию/JSON и не влияет на рекорды.

Новая комплексная проверка: `.venv\Scripts\python tools\development_test.py`. Папка для переноса остаётся `dist`, архив — `XENOCIDE-offline.zip`.
